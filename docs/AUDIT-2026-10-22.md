## На чём остановились

В main уже включены обнаружение Abilities, read-only доступ `ability.list` /
`ability.get` через Cloud, проверки реального Native MCP/REST в CI и развитие
контрактов квот. Последние #70–#72 проверяют резервирование при неопределённом
исходе, запрет повторной отправки, подтверждение оператором и однократное
завершение с успешным либо ошибочным результатом.

Публичный выпуск ещё требует staging-приёмки, сверки установленных файлов,
безопасного upgrade/rollback и отдельного решения о публикации. Новые функции
не должны обходить эти проверки.

внешнего API не заявляется.
