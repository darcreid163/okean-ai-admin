# Возможности WP AI Admin — 23 октября 2026

Native 2.1.17 (DB24) + Cloud 0.3.13-dev (schema4) — кандидат разработки.
«Реализовано» ниже означает наличие кода и указанных проверок. Это не подтверждает
установку этого кода на рабочие сайты. Последний предоставленный владельцем health
Cloud показывал 0.3.11, OAuth включён, Batch/billing/commercial entitlements выключены.
Совпадение установленных файлов с main по SHA ещё не подтверждено. Текущий контроль
выпуска: [#40](https://github.com/darcreid163/okean-ai-admin/issues/40).

| Возможность | Плагин Native на сайте | Сервер Cloud | Готовность и условия |
|---|---|---|---|
| Диагностика и чтение WordPress | Статус, здоровье, контент, тема, плагины, доступные сущности и метаданные | Получает каталог и вызывает разрешённые инструменты выбранного сайта | Реализовано; доступ ограничен полномочиями |
| Gutenberg и обычный контент | Чтение/поиск блоков, точечные изменения текста и блоков через sandbox | Передаёт вызовы Native | Реализовано; есть реальные WordPress регрессии |
| Elementor | Структура, виджеты, настройки, фрагменты HTML, контейнеры, layout и создание черновиков | Передаёт вызовы Native | Реализованные пути проверяются с Elementor; полный произвольный document executor ещё не выпущен |
| WooCommerce | Поиск/чтение товаров, вариации, цены, остатки, создание черновиков и sandbox-правки | Передаёт вызовы Native | Реализовано при наличии WooCommerce; lifecycle и округление проверяются |
| Медиа | Загрузка и импорт изображений, alt/title и featured image через sandbox | Передаёт вызовы; новый поиск Unsplash отдельно | Реализовано; формат должен поддерживаться редактором изображений сайта |
| Меню | Создание, добавление/удаление/перемещение пунктов и назначение location | Передаёт вызовы Native | Реализовано через sandbox/lifecycle; полная пользовательская staging-матрица ещё нужна |
| Файлы и workspace | Чтение разрешённых файлов темы, diff, изолированный workspace и предложения правок | Передаёт вызовы Native | Реализованы ограниченные пути; произвольного shell/SQL или записи во всю ФС нет |
| Настройки и Woodmart | Безопасные option sandbox; отдельный адаптер Woodmart | Передаёт вызовы Native | Защищённые ключи запрещены; Woodmart требует соответствующую тему и отдельную приёмку |
| Подтверждение и откат | Sandbox → approval → apply → verify → receipt/proof → rollback | Сохраняет ответы и исходы обращений | Реализовано; права и разрешённый режим lifecycle обязательны |
| Подключение нескольких сайтов | Локальная идентичность и защищённый MCP | OAuth PKCE, выбор сайтов, изоляция аккаунтов, отзыв и refresh | Реализовано и тестируется; обновление внешнего клиента после expiry ещё в релизной приёмке |
| Общая квота и повторы Cloud | Поддерживает центральный режим без двойного локального учёта | Ledger, резервы, повтор с тем же ключом, удержание неопределённых исходов | Реализовано; миграция действующих тарифов не выполнена автоматически |
| Пакетные вызовы Cloud | Выполняет разрешённые read/sandbox элементы | До 20 элементов, покомпонентный учёт и batch receipt | Реализовано и тестируется; требуется явное включение политики; последний live health — OFF |
| Новое: Abilities | Обнаружение opt-in Abilities и чтение их описаний | `ability.list` / `ability.get` классифицируются как чтение | Реализовано; произвольный запуск Ability не включён |
| Новое: серверные Skills | Использует штатные инструменты для описанного процесса | Закрытая библиотека: список и загрузка инструкций | Реализовано; загрузка инструкции не исполняет действия и не даёт новых прав |
| Новое: Unsplash | Выбранное изображение можно затем передать штатному media sandbox | Поиск метаданных изображений с серверным ключом | Реализовано; нужен настроенный ключ и доступ к API; живой запрос в этой работе не проверялся |
| Новое: расширенные команды чтения | `wordpress.execute`: контролируемый реестр чтения; запись — plan_only | Доставляет разрешённый вызов | Реализовано; тест охватывает 43 записи реестра и 35 обработчиков; это не произвольный WP-CLI |
| Новое: проверки медиа и критических options | Байты/MIME/расширение/декодирование; защита новых и исторических approval/apply | Сохраняет ограничения Native | Исправления #94/#96 проверены в CI; изображения до 10 MiB/20 MP |
| Новое: защита путей в доказательствах | Публичные метаданные и исторические receipt/proof проецируются без путей сервера | Аналогичная защита свежих и старых кешированных ответов | #98/#100 реализованы; исходные доказательства/хеши и редактируемые байты сохраняются |
| Новое: единый риск операций | Одна политика для каталога и всех зарегистрированных создателей операций | Получает результат с сохранённой классификацией | #102 реализован; 28 классов и 15 реальных операций проверены |
| Новое: запрет одинаковых pending-правок | Атомарный guard новых правок существующих объектов | Получает ошибку повтора; собственный ledger не меняется | Первый этап #104; новые артефакты, workspace и старые строки без fingerprint остаются в #103 |
| Оплаты и коммерческий запуск | Лицензионные ограничения присутствуют | Автоплатежи, автоматический upgrade тарифа и полный коммерческий контур не завершены | Не считать готовым платным сервисом |

Новые функции должны работать после установки согласованных проверенных сборок,
настройки требуемых ключей/политик и прохождения приёмки окружения. Автоматические
проверки не заменяют установку, проверку SHA, резервные копии и реальный внешний
OAuth/мутационный сценарий. Production-развёртывание в этой работе не выполняется.
