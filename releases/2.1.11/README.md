Автоматическое подключение сайта — 2026-10-07

1. WordPress → Плагины → Добавить плагин → Загрузить плагин. Обновите существующий WP AI Admin архивом wp-ai-admin-2.1.11.zip на wpaiadmin.ru и okean.market. Подтвердите замену установленной версии.
2. Аналогично обновите WP AI Admin Cloud Core архивом wp-ai-admin-cloud-0.3.5.zip только на wpaiadmin.ru. Сохранённый тестовый gateway остаётся включённым; ключи заново создавать не нужно.
3. Откройте https://wpaiadmin.ru/wpai-cloud/connect под своей учётной записью. Введите https://okean.market и нажмите «Подключить автоматически».
4. На okean.market войдите как администратор и нажмите «Подключить сайт». Проверьте, что указан ваш кабинет на wpaiadmin.ru. Токен создаётся и передаётся между серверами автоматически; сайт появляется в кабинете.
5. Повторите для https://wpaiadmin.ru.
6. Подключите AI-клиент к https://wpaiadmin.ru/mcp. В браузере авторизуйтесь в центральном кабинете и разрешите нужные сайты. Установка плагинов сама по себе не добавляет подключение в аккаунт ChatGPT.

PowerShell, пароль приложения и копирование MCP-токена для этой схемы не нужны. Повторное подключение активного сайта обновляет ключ без дубликата. Доступ можно отозвать на подключённом сайте в WP AI Admin → «Подключения к gateway»; отключение MCP останавливает обращения к сайту. Подтверждение подключения не включает AI Lifecycle Control/Test Automation. Обновление сборки возвращает эти отдельные режимы к ручному подтверждению, как в предыдущих версиях.

Проверено: 38 тестовых проверок подключения двух сайтов; 21 проверка на настоящем WordPress; PHP 8.2/8.3/8.4; SQLite/MySQL; сохранение OAuth и идентификаторов при обновлении. Оба CI workflow прошли. Настоящая авторизация ChatGPT/Qwen на ваших доменах проверяется после установки. Текущий доступ — тестовая схема с одобренными учётными записями.
