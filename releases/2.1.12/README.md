# WP AI Admin 2.1.12 — рабочий стол и подключения

Установите wp-ai-admin-2.1.12.zip на wpaiadmin.ru и okean.market через «Плагины → Добавить плагин → Загрузить плагин», подтвердив замену существующей версии. Cloud Core 0.3.5 обновлять не требуется.

Основной пункт WP AI Admin открывает «Рабочий стол» со всеми прежними элементами управления: MCP, AI Lifecycle Control, Test Automation, операции, подтверждение, применение и откат. На рабочем столе доступны кнопки автоматического подключения сайта и управления подключениями. Подменю «Подключения к gateway» открывает отдельную страницу с кнопкой возврата на рабочий стол.

Правильные адреса рабочего стола:
- https://wpaiadmin.ru/wp-admin/admin.php?page=okean-ai-admin
- https://okean.market/wp-admin/admin.php?page=okean-ai-admin

Страница подключений: /wp-admin/admin.php?page=oai-gateway-connections. Использование bare /wp-admin/oai-gateway-connections исправлено через регистрацию правильного меню. Центральный кабинет: https://wpaiadmin.ru/wpai-cloud/connect; gateway: https://wpaiadmin.ru/mcp.

Причина: в 2.1.11 подменю подключений регистрировалось раньше родительского меню. Исправление регистрирует родителя, явный первый пункт «Рабочий стол» и подменю подключений в одном обработчике, в правильном порядке. Идентификаторы, OAuth и парные ключи сохраняются. При смене сборки действует прежний сброс отдельных AI/Test автоматических разрешений.

Проверено: 29 проверок реального меню и HTML обоих экранов в настоящем WordPress; воспроизведение ошибки на точном архиве 2.1.11, затем успешный повтор на 2.1.12; 21 проверка browser pairing; все существующие CI проверки native/Core прошли на PHP 8.2/8.3/8.4, SQLite/MySQL и двух профилях WordPress. Проверка на ваших доменах остаётся после установки нового архива.
