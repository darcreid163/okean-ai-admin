# Woodmart Compatibility
Detect Woodmart/version; separate generic WP operations from theme-specific workflows. Inspect actual option keys, builder structures and public APIs before editing. Preserve unknown theme options, header/footer layouts, product templates, conditions and custom metadata. Never overwrite theme-specific data with generic defaults. Respect Elementor presence/version. Use backup/diff and explicit approval for high-impact settings. Verify persisted settings and rendered view when possible. Do not claim universal compatibility without matrix evidence. Use synthetic fixtures, never customer exports.
